ObjectUtils 테스트

ObjectUtils는 객체 처리를 위한 유틸리티입니다.
객체 변환, null 체크, 비교 등의 기능을 제공합니다.

ResponseUtils 예제

ResponseUtils는 API 응답을 통일된 형식으로 반환하기 위한 유틸리티입니다.
모든 API 응답은 다음과 같은 형식을 따릅니다: 

{
    "success": true,
    "message": "Success",
    "data": { ... },
    "errorCode": null,
    "timestamp": 1234567890
}
